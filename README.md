# 夜市猫 Night Market Cat

WASD 走路。盯摊灯，绿灯偷今晚三口。

> 仓库：[https://github.com/heboluo/night-market-cat](https://github.com/heboluo/night-market-cat)

## 怎么玩

- **WASD** 或方向键走路，松开就停；也可按住鼠标 / 手指指向方向
- 先吃发光的小吃让自己变大
- 金色箭头是今晚下一目标；摊上绿灯才能偷，红灯会被看见
- 惊动两星开始被追，三星再被碰到就抓
- 三口吃完算赢；牌坊是隐藏的王

## 本地开发

需要 Node.js 20+。

```bash
npm install
npm run dev
```

```bash
npm run typecheck
npm run build
```
