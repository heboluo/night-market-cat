# 夜市猫 Night Market Cat

像素风夜市。WASD 走路。绿灯偷箭头那一口。

> 仓库：[https://github.com/heboluo/night-market-cat](https://github.com/heboluo/night-market-cat)

## 怎么玩

- **WASD** 走路，松开就停；按住鼠标也能走
- 先吃发光的小鱼丸让自己变大
- 金色箭头是今晚要偷的东西
- 摊上绿灯才能偷（目标上是绿勾）；红灯会亮红叉，硬偷会被看见
- 惊动两星开始被追，三星再被碰到就抓
- 偷满三口算赢

## 本地开发

```bash
npm install
npm run dev
```
