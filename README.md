# 夜市猫 Night Market Cat

WASD 走路。今晚只想吃三口。乱吞会惊动摊主。

> 仓库：[https://github.com/heboluo/night-market-cat](https://github.com/heboluo/night-market-cat)

## 怎么玩

- **WASD** 或方向键走路，松开就停
- 也可以按住鼠标 / 手指指向要去的方向
- 金色箭头指着今晚下一口
- 先吃小的让自己变大，再去吃清单上的东西
- 乱吞摊位会加惊动；三星再被碰到就抓
- 三口吃完算赢；牌坊是隐藏的王

## 本地开发

需要 Node.js 20+。

```bash
npm install
npm run dev
```

```bash
npm run typecheck
npm run build
```
