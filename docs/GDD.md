# 夜市猫 设计说明

## 一句话

WASD 走路。今晚只想吃三口；乱吞大家伙会惊动摊主。

## 玩家体验

站着不动时猫是静止的。玩家自己走去偷吃。金色箭头指出下一口，先变大再吃清单，乱来就会被追。

## 核心循环

1. 玩家用 WASD 或按住鼠标控制猫
2. 先吃小零食让自己变大
3. 吃掉金色箭头指出的那一口，推进清单
4. 乱吞摊位、家具会加惊动；两星开始被追，三星碰到猎人就抓
5. 三口吃完算赢；吞掉牌坊算王

## 操作

WASD / 方向键走路。也可以按住鼠标或手指指向方向。松开就停。

## 难度

- 没有总倒计时。压力来自清单和惊动，不是钟
- 目标往往比你大，必须先吃小的
- 吃错大家伙会招摊主
- 被追上可以躲开或反吃

## 画面

像素风：限定色盘、硬边剪影、禁止抗锯齿。停下时用静止帧。

## 范围
