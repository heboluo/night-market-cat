# 夜市猫 设计说明

## 一句话

跟着指针走，碰到就吃，越吃越大。没有失败，只有打烊。

## 玩家体验

第一秒知道怎么玩，第十秒觉得吞东西很爽，第三分钟想再吞一次牌坊。

## 核心循环

1. 猫跟随鼠标 / 手指
2. 吞掉比自己小的物体并变大
3. 镜头拉开，原本巨大的摊位变成零食
4. 倒计时结束结算，再开一局

## 操作

只有一种：跟随指针。没有跳跃、背包、技能栏、教程弹窗。

## 失败

没有 Game Over。撞上更大的物体只会被弹开。

- 菜单、一局游戏、结算

### v0.2 夜市和手感

- 更像夜市的摊位与灯笼
- 吞掉大家伙时的音画反馈

### v0.3 完整一局
