# 夜市猫 设计说明

## 一句话

像素风夜市。WASD 走路，绿灯偷金色箭头那一口。

## 玩家体验

猫停在原地等你。小吃随时能垫肚子。清单上的那一口必须趁摊灯变绿。目标上会直接出现绿勾或红叉。

## 核心循环

1. 先吃发光小鱼丸
2. 跟着金色箭头走到目标
3. 红灯（红叉、摊上叹号）就等；绿灯（绿勾）就偷
4. 偷满三口算赢；硬偷会被看见并招摊主

## 画面

像素风：限定色盘、硬边、最近邻放大。不做写实或矢量渐变。

## 范围

### v0.5 像素风与可读机制（当前）

- 统一像素美术
- 圆头橘猫
- 目标上的红叉 / 绿勾
