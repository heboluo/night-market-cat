# 夜市猫 设计说明

## 一句话

WASD 走路。盯着摊灯，绿灯偷今晚三口。

## 玩家体验

猫停在原地等你。街是一条挤满灯笼和摊位的夜市。小吃随时能垫肚子；清单上的那一口必须趁摊主不注意。

## 核心循环

1. 玩家用 WASD 或按住鼠标控制猫
2. 先吃摊边小吃让自己变大
3. 金色箭头指出今晚下一目标
4. 目标、家具、摊位都受最近摊灯保护：红灯偷会被看见并加惊动
5. 每偷成一口，绿灯窗口变短
6. 两星开始被追，三星被碰到就抓
7. 三口吃完算赢；吞掉牌坊算王

## 操作

WASD / 方向键走路。也可以按住鼠标或手指指向方向。松开就停。

## 难度

- 没有总倒计时。压力来自摊灯、体型和惊动
- 目标往往比你大，必须先吃小的
- 越到后面绿灯越短
- 被追上可以躲开或反吃收摊车

## 画面

手绘式夜市街：天空、店面、湿路面、灯笼串和蒸汽。物体用更高分辨率绘制并开抗锯齿。
