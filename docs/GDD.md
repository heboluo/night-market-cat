# 夜市猫 设计说明

## 一句话

跟着指针走，碰到就吃，越吃越大。开局没有门槛，但夜市会饿、会追。

## 玩家体验

第一秒知道怎么玩，第十秒觉得吞东西很爽，后面会因为饥饿、电动车和收摊车而紧张。吞下牌坊才算真正赢。

## 核心循环

1. 猫跟随鼠标 / 手指
2. 吞掉比自己小的物体并变大
3. 不吃就会饿瘪，电动车会撞小体型
4. 收摊车出发后必须长大到能反吃，或绕开
5. 目标是吞掉夜市牌坊；否则按体型结算

## 操作

只有一种：跟随指针。没有跳跃、背包、技能栏、教程弹窗。

## 难度

- 开局周围有零食，任何人都能吃到第一口
- 饱食会掉，停下来就会变小
- 必须明显大于目标才能吞（不能擦边吃掉摊位）
- 22 秒后收摊车追来；太小会被撵走，够大可以反吃

## 画面

像素风：限定色盘、硬边剪影、禁止抗锯齿、统一像素尺度。灯光从左上来，阴影偏冷。
